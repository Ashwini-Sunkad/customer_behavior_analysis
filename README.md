# customer_behavior_analysis
Data analytics project showcasing customer behavior analysis using python, sql and power bi 

# Project Overview
This project demonstrates an end-to-end data analytics workflow, starting from raw data and transforming it into meaningful business insights through Python, MySQL, Power BI, and Gamma.

# Objective
The main objective of this project is to:

Understand and clean raw business data
Perform exploratory data analysis using Python
Identify important trends, patterns, and relationships
Use MySQL to perform business-focused SQL analysis
Build an interactive Power BI dashboard
Generate a professional analytical report
Present key findings through a professional presentation.

# Dataset
The project uses a structured business dataset containing information such as:

Customer details
Product/category information
Sales transactions
Revenue
Quantity
Dates
Regions/locations
Customer segments
Other relevant business attributes
